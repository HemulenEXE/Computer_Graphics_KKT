# Лабораторная №7: отсечение нелицевых граней (часть 1)

Запуск: `dotnet run --project PolyhedraLab.csproj`.

## Как показать результат

1. Выберите «Гексаэдр (куб)» или «Шар» и нажмите «Создать / сбросить». Можно открыть свою модель через «Открыть OBJ».
2. В группе «Проекция» включите «Каркас (без Z-буфера)».
3. Переключайте «Скрывать нелицевые грани»: без отсечения виден весь каркас, с отсечением остаются рёбра лицевых граней. При исходном ракурсе у куба передаются на отрисовку 3 грани из 6. Счётчик расположен под изображением.
4. Включите «Нормали граней», чтобы увидеть оранжевые стрелки наружу от центров граней.
5. Включите «Вращать объект вокруг Y». Объект вращается вокруг своего центра со скоростью 45°/с; камера при этом остаётся на месте. После выключения вращения координаты и нормали в текстовом отчёте обновятся.
6. Изменяйте направление взгляда полями «Камера: азимут Y°» и «наклон X°» либо перемещайте мышь с зажатой средней кнопкой. Текущий вектор направления показан под изображением.
7. Переключите проекцию на перспективную. Выключите каркас для отрисовки с существующим Z-буфером.

## Что реализовано

- `Polygon.Normal` хранит единичную нормаль грани, `Polygon.Center` — её центр.
- В `Polygon.UpdateNormal` вычисляются векторные произведения `(B − A) × (C − A)`. Для многоугольника суммируются произведения по вееру треугольников, поэтому три первые коллинеарные вершины не мешают вычислению. Вырожденная грань получает нулевую нормаль и пропускается при отрисовке.
- Направление нормали проверяется по вектору от центра объекта к центру грани. Если скалярное произведение отрицательно, нормаль меняет знак. Этот способ определения внешней стороны рассчитан на выпуклые тела, включая куб и шар; для произвольных вогнутых и открытых OBJ-поверхностей он не гарантирует правильную ориентацию.
- `Polyhedron.UpdateFaceNormals` пересчитывает нормали по текущим вершинам при создании и перед проецированием. Поворот, неравномерный масштаб и отражение учитываются без отдельного преобразования старой нормали.
- В `Projector.Project` задаётся вектор `D` от наблюдателя к объекту. Для параллельной проекции это `Camera.Direction`; для перспективной — `Center + Offset − Camera.Position` отдельно для каждой грани.
- Грань лицевая, если `N · D < 0`. Значения около нуля считаются ребром к наблюдателю и отсекаются с небольшим допуском. При включённом отсечении нелицевые грани не передаются на отрисовку, в том числе в Z-буфер. При выключенном отсечении передаются обе стороны.
- Каркас позволяет увидеть работу части 1 отдельно: в режиме сплошной заливки Z-буфер сам скрывает заднюю поверхность, поэтому переключение отсечения на выпуклом непрозрачном теле почти не меняет изображение.

Отсечение нелицевых граней определяет сторону поверхности, обращённую к наблюдателю. Видимость оставшихся граней при перекрытии объектов по-прежнему определяет Z-буфер.

## Проверка

`dotnet run --project tests/CullingChecks.csproj`

Проверяются нормали встроенных моделей, смена ракурса и проекции, смещение объекта в перспективе, поворот, масштабирование и отражение, обратный порядок вершин, вырожденные грани, совместимость с Z-буфером, элементы интерфейса и вращение объекта.
